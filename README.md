# Suryansh Singh Portfolio

A responsive portfolio foundation built in plain HTML, CSS, and vanilla JavaScript.

## Structure

- `index.html` — page shell and semantic section scaffolding
- `css/` — design system, responsive styles, and animation rules
- `js/` — project data and interaction setup
- `assets/` — images, icons, and screenshots for future project previews

## Notes

This is the foundation phase of the portfolio. The next chunk will replace placeholder project data and expand the interactive experience with richer content and project previews.
